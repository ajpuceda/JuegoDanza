# 💃 JuegoDanza

Juego web de **danza clásica** para los más pequeños. Ayuda a **Lucía** — una bailarina rubia, con gafas y pelo recogido en moño — a practicar sus pasos de ballet en un escenario de teatro.

## 🎮 Cómo se juega

- **Baile libre** 🩰: pulsa los botones del panel lateral y Lucía hará cada movimiento de danza clásica.
- **Sigue la clase** 🎵: la profesora pide movimientos al azar; pulsa el botón correcto antes de que se acabe el tiempo. Gana puntos y rachas, ¡y consigue las 3 estrellas!

## 🩰 Movimientos incluidos

Plié · Tendu · Relevé · Arabesque · Pirueta · Grand Jeté · Port de Bras · Cambré

Cada movimiento tiene su propia nota musical (como un tambor) ✨

## 🚀 Jugar

Abre `index.html` en cualquier navegador — no necesita instalación, dependencias ni internet.

También puedes activarlo en GitHub Pages: **Settings → Pages → Deploy from branch → main** y se publicará en:

`https://ajpuceda.github.io/JuegoDanza/`

## 🛠️ Tecnología

HTML, CSS y JavaScript puros con SVG animado. Sin frameworks, un solo archivo.
